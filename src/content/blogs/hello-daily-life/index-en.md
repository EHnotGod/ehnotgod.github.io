# Welcome to Daily Life

This is the **Daily Life** column — somewhere to jot down everyday bits: what I did today, what I was thinking about, the small moments worth keeping. It is far looser than the algorithm notes; a plain log or a bit of rambling are both fine here.

This first post doubles as a template. To write a new entry later, just create a folder and drop an `index.md` inside (or `index-en.md` for an English version like this one), and set `category` to `daily-life` in the frontmatter so it is filed under this column automatically:

```md
---
title: "Diary · 2026-09-04"
publishDate: 2026-09-04
description: "One line summarising the day."
category: daily-life
tags:
  - 日常
language: en
---
```

It does not have to be well written — getting it down is already the win.
